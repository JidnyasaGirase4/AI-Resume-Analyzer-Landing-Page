# AI Resume Analyzer — Landing Page

A modern, responsive landing page for an AI-powered resume analyzer, built with React and Vite.

## Live Demo

[https://jazzy-cocada-a44029.netlify.app/](https://jazzy-cocada-a44029.netlify.app/)

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React (icons)

## Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

Deployed on Netlify with automatic deploys from the `main` branch.
